# 七、V0：把现在Baseline变成Shared Kernel

当前你的Kernel已经使用：

```text
Shared Memory Reduction
```

因此把它定义成：

> **V0 / Shared**

创建：

```bash
nano ops/cuda/rmsnorm/src/rmsnorm_shared.cu
```

核心逻辑从旧Baseline中迁移。

Kernel：

```cpp
#include "rmsnorm.cuh"

namespace hqsb {
namespace cuda_ops {

__global__ void rmsnorm_shared_kernel(
    const float* input,
    const float* weight,
    float* output,
    int hidden,
    float epsilon)
{
    extern __shared__ float smem[];

    const int row = blockIdx.x;
    const int tid = threadIdx.x;

    const size_t base =
        static_cast<size_t>(row) *
        static_cast<size_t>(hidden);

    float local_sum = 0.0f;

    for (int i = tid; i < hidden; i += blockDim.x) {
        const float x = input[base + i];
        local_sum += x * x;
    }

    smem[tid] = local_sum;

    __syncthreads();

    for (unsigned int stride = blockDim.x / 2;
         stride > 0;
         stride >>= 1)
    {
        if (tid < stride) {
            smem[tid] += smem[tid + stride];
        }

        __syncthreads();
    }

    const float inv_rms =
        rsqrtf(
            smem[0] /
            static_cast<float>(hidden)
            + epsilon
        );

    for (int i = tid; i < hidden; i += blockDim.x) {
        output[base + i] =
            input[base + i] *
            inv_rms *
            weight[i];
    }
}

cudaError_t launch_rmsnorm_shared_f32(
    const float* input,
    const float* weight,
    float* output,
    const RmsNormConfig& config)
{
    const dim3 grid(config.rows);
    const dim3 block(config.threads);

    const size_t shared_bytes =
        static_cast<size_t>(config.threads) *
        sizeof(float);

    rmsnorm_shared_kernel<<<
        grid,
        block,
        shared_bytes,
        config.stream
    >>>(
        input,
        weight,
        output,
        config.hidden,
        config.epsilon
    );

    return cudaGetLastError();
}

}  // namespace cuda_ops
}  // namespace hqsb
```

注意这里不负责：

```text
cudaMalloc
cudaMemcpy
cudaDeviceSynchronize
```

算子层只负责Launch。

这是后面接PyTorch、vLLM、TensorRT时必须具备的设计。

# 八、V1：实现Warp Shuffle

这才是当前阶段第一个真正的优化。

新建：

```bash
nano ops/cuda/rmsnorm/src/rmsnorm_warp.cu
```

首先写Warp Reduce：

```cpp
__device__ __forceinline__
float warp_reduce_sum(float value)
{
    constexpr unsigned int mask = 0xffffffff;

    for (int offset = 16; offset > 0; offset >>= 1) {
        value += __shfl_down_sync(
            mask,
            value,
            offset
        );
    }

    return value;
}
```

然后Block级Reduction：

```cpp
template<int BLOCK_SIZE>
__global__ void rmsnorm_warp_kernel(
    const float* input,
    const float* weight,
    float* output,
    int hidden,
    float epsilon)
{
    constexpr int WARP_SIZE = 32;

    __shared__ float warp_sums[32];
    __shared__ float shared_inv_rms;

    const int row = blockIdx.x;
    const int tid = threadIdx.x;

    const int lane = tid % WARP_SIZE;
    const int warp_id = tid / WARP_SIZE;

    const size_t base =
        static_cast<size_t>(row) *
        static_cast<size_t>(hidden);

    float local_sum = 0.0f;

    for (int i = tid; i < hidden; i += BLOCK_SIZE) {
        const float value = input[base + i];
        local_sum += value * value;
    }

    local_sum = warp_reduce_sum(local_sum);

    if (lane == 0) {
        warp_sums[warp_id] = local_sum;
    }

    __syncthreads();

    if (warp_id == 0) {

        const int warp_count =
            BLOCK_SIZE / WARP_SIZE;

        float block_sum =
            lane < warp_count
            ? warp_sums[lane]
            : 0.0f;

        block_sum =
            warp_reduce_sum(block_sum);

        if (lane == 0) {
            shared_inv_rms =
                rsqrtf(
                    block_sum /
                    static_cast<float>(hidden)
                    + epsilon
                );
        }
    }

    __syncthreads();

    const float inv_rms =
        shared_inv_rms;

    for (int i = tid; i < hidden; i += BLOCK_SIZE) {
        output[base + i] =
            input[base + i] *
            inv_rms *
            weight[i];
    }
}
```

# 九、为什么Warp Shuffle应该更快

这部分一定要真正理解。

V0：

```text
shared memory
↓
__syncthreads()
↓
shared memory
↓
__syncthreads()
↓
...
```

256线程Reduction大概需要：

```text
8轮同步
```

Warp Shuffle：

```text
register
↓
shuffle
↓
register
```

Warp内部不需要Block级同步。

最终只剩：

```text
warp内部reduce
↓
warp leader写shared
↓
一次block同步
↓
第一个warp reduce
```

因此理论上：

```text
同步次数 ↓
shared memory流量 ↓
```

但是：

> 不允许直接写“Warp Shuffle一定更快”。

需要Profiler验证。

因为最终性能还可能由：

```text
HBM/DRAM bandwidth
```

主导。

# 二十九、Vectorized Kernel思路

输入：

```cpp
const float4* input4 =
    reinterpret_cast<const float4*>(input);

const float4* weight4 =
    reinterpret_cast<const float4*>(weight);

float4* output4 =
    reinterpret_cast<float4*>(output);
```

一次处理：

```text
4 × FP32
```

而不是：

```text
1 × FP32
```

累计：

```cpp
float4 x = input4[index];

local_sum +=
    x.x * x.x +
    x.y * x.y +
    x.z * x.z +
    x.w * x.w;
```

写输出同理。
