### 2.1 细节

`compute_metrics` 计算 5 项指标；correctness 测试对每个 (dtype, shape, variant)
组合断言 `max_abs_error <= tol`（FP32 5e-4 / FP16 2e-2）。FP16 阈值放宽系 half
相对精度（2^-11）所致。

### 2.2 细节

非 2 次幂 hidden（100/500/1536）、极小 hidden（1/2/3）、极大 hidden（4096）、
极值（全零/1e6/1e-6/1e10 交替）均通过。对齐陷阱（FP16 奇数 hidden、FP32 非
4 倍数 hidden）通过 vectorized kernel 的 scalar-tail 回退 + dispatcher 路由解决。

### 2.3 细节

`compute-sanitizer --tool memcheck --leak-check full` 报 "GPU debugging features
are disabled"（Jetson L4T 平台限制）但 host 泄漏检查通过（0 bytes leaked）。
GPU 越界由 correctness 的边界 case + 对齐修复间接覆盖。

### 2.5 细节

`rmsnorm_select_variant`：FP16→V2；FP32 hidden%4==0→V2，否则→V1。
`rmsnorm_forward` 对 `kReference`、null 指针、非正 shape、FP16+V0 返回
`cudaErrorInvalidValue`（明确 fallback，不静默）。

| 4 | 对模型端到端预期收益给 Amdahl 上限，不夸大 micro speedup | PASS | 见 §3.1 |

### 3.1 Amdahl 上限（不夸大 micro speedup）

S02 实测 decode 中 RMSNorm + elementwise 类合计 ~10%（copy_ 2.9% + mul 2.1% +
cat 1.4% + 其他）。即使 RMSNorm 单算子加速 2x，decode 端到端增益上限
`≈ 1/(1 - 0.10*0.5) ≈ 1.05x`（5%）。**不夸大**：报告明确 RMSNorm 是教学算子 +
elementwise 路径的闭环案例，真正的大头（GEMM ~78%）需走 CUTLASS/低比特（S04/S05）。

fused residual+rmsnorm 融合的理论 traffic 收益 1.2x（6n→5n），当前 V0/V1 因
RAW 依赖未完全兑现，已登记后续项。

## 6. 已知缺口（不阻塞 S03 验收）

- **nsys/ncu 未在本阶段采集**：Jetson L4T 下 ncu metric 受限（与 S02 相同）；
  已用 Roofline + benchmark 双口径计时 + occupancy 查询作为替代硬件证据。
- **compute-sanitizer GPU debug 受 L4T 限制**：host 泄漏检查通过（0 bytes
  leaked），GPU 越界需 datacenter GPU 复核。
- **FP16 half8 优化未做**：half2 退化已定位（32-bit 事务），half8（float4 装
  8 个 half）优化按"不追加无假设变体"原则登记为后续项。
- **fused 寄存器驻留优化未做**：RAW 依赖已定位，消除方案（寄存器暂存 add 结果）
  登记为后续项。
