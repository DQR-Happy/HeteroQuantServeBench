## 4. 逐模块说明（含调用示例）

### 4.1 量化语义冻结与自实现 RTN

```python
from hqsb.quant.spec import MAIN_W4_GROUP, QuantScheme, RangePolicy
from hqsb.quant.rtn import quantize, reconstruction_report

scheme = MAIN_W4_GROUP                       # INT4, per-group G=128, symmetric
qt = quantize([float(i) for i in range(256)], scheme, shape=(2, 128))
report = reconstruction_report([float(i) for i in range(256)], qt.values_dequant)
# report: max/mean/RMSE/cosine/L2-relative/SQNR/first_mismatch
```

关键契约：`QuantScheme` 对 bit×granularity×symmetric×G 的非法组合**构造时即
拒绝**（例如 symmetric+twos_complement 歧义、per-channel 声明 group_size、
per-group 缺 group_size）；`factorial_matrix()` 预注册 expected-reject 单元，
测试证明非法组合不会被静默接受。

### 4.2 packing 与 kernel layout

```python
from hqsb.quant.packing import pack_kernel_variant, unpack_kernel_variant, unpack_independent

packed = pack_kernel_variant(qt.q, qt.scales, qt.zeros, qt.scheme, rows=2, cols=128)
assert unpack_kernel_variant(packed, qt.scheme) == qt.q          # 主 decoder
assert unpack_kernel_variant(packed, qt.scheme, independent=True) == qt.q  # 独立 decoder
```

canonical 编码冻结为 `hqsb.nibble.v1`（低半字节先、奇数元素高半字节补零、
补零必须为 0 否则拒绝）；kernel layout 显式列出 nibble order 与
`parent_canonical_hash`。非整数 code、非正 scale、未知 layout、payload 长度
不符均在打包/解包前拒绝。

### 4.3 QuantArtifact 制品

```python
from hqsb.quant.artifact import QuantArtifactDocument, ModelIdentity, load_document

doc = QuantArtifactDocument.from_quantized(qt, tensor_name="q_proj.weight",
        source_dtype="float16", source_sha256="...", model=ModelIdentity(model_id="Qwen/Qwen3-1.7B", revision="main"))
doc.add_variant(packed, target_arch="sm_86")
path = doc.save("experiment_results/S05/.../artifact")
loaded = load_document(path)          # 新进程重载，identity/canonical hash 稳定
```

`save()` 原子写（临时目录 fsync 后 rename），`load_document` 校验 schema/
模型身份/量化语义/packed 变体（独立 decoder 逐值比对），未知 scheme 字段
拒绝而非丢弃。

### 4.4 兼容、故障注入、repack

```python
from hqsb.quant import compat, faults
decision = compat.check_compatibility(doc, capability, expected_model=..., mode=compat.MODE_STRICT)
# DIRECT_LOAD / REPACK_REQUIRED / REQUANTIZE_REQUIRED / EXPLICIT_FALLBACK / REJECT
new_doc, provenance = compat.repack(doc, target_layout_id)   # 全不变量校验
results = faults.run_fault_matrix(golden_dir, scratch_dir, capability)  # 35 例全捕获
```

### 4.5 低比特 kernel（真实 fused-dequant 路径）

```python
from ops.quant.executors import get_executor
```

## 7. 关键 bug 修复与决策记录

1. **非末轴量化（axis=0）分片错误**：原按「行 = index // k」分片，对
   axis=0 会量化错误的元素。改为通用 `unit_of_index`（按轴坐标分解），并
   让 `dequantize_flat` 接收 `shape` 而非 rows/k。测试 `test_per_channel_axis_zero`
   与 `test_axis0 scales` 固定该行为。
2. **`pack_canonical` 静默截断非整数 code**：改为拒绝非整数 code（负向对照
   `test_pack_canonical_rejects_non_integer_code`）。
3. **`pack_kernel_variant` 未校验 scale 有限/正**：补上校验（负向对照
   `test_pack_refuses_non_positive_scale`）。
4. **canonical_hash 覆盖模型身份导致「模型篡改」被误判为「量化语义」**：
   将 `canonical_hash` 收窄到量化语义 + 数据，模型身份走独立的
   `identity_hash`（E05-01 §8「identity 与 provenance 分离」）。
5. **coverage 线性投影后缀匹配未剥离 `.weight`**：修复 `classify_weight`
   先剥离 `.weight` 再匹配，`down_proj.weight` 正确判为 `default_linear`。
6. **fault 矩阵 35 例逐个校正**：早期版本多处 expected-stage/action 与真实
   拒绝阶段不一致（例如 packed 载荷 bit-flip 应落 `pack` 阶段）；逐例对齐后
   35/35 全捕获。

决策（依据文档）：`ops/quant` 作为执行层，只消费 `hqsb/quant` 语义层，不
定义量化数学（依赖方向：`ops` → `hqsb`）；`hqsb.quant` 不 import torch/triton
（全部惰性导入），保证 CPU-minimal 环境可 import 并返回结构化能力错误。
