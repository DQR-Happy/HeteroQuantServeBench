## 1. 总体目标

按 `docs/stages/S06_框架集成与图优化.md` 与
`docs/architecture/HQSB_项目完整剖析.md` §15，本阶段要证明：S03–S05 的算子与
量化能力可以**通过 PyTorch 稳定契约**（operator schema → dispatcher →
Meta/FakeTensor → Dynamo/Export/FX → pattern rewrite → lowering → compiled
artifact/cache → actual kernel → Qwen block/model）被图系统消费，并且在动态
shape、版本变化、编译失败、并发 stream、反复启停和跨模型复用时仍保持：语义
正确、dispatch 可解释、guard/break 可观测、cache 不误命中、fallback 确定性、
资源可回收、收益可从 graph/kernel/allocation 解释。

**本次交付的边界**（遵循任务约束「提供接口，但不执行实验」）：

- **已交付**：E06-01 ~ E06-11 全部 **218 个实验步骤**所依赖的能力、函数、
  数据结构、驱动入口与支撑模块；以代码 + 371 个新增测试证明其成立。
- **未交付（实验层）**：任何正式实验执行，以及任何 graph count / guard /

## 4. 逐模块说明（含可直接复制的调用示例）

### 4.1 算子 schema 是编译契约（`specs.py`）

```python
from hqsb.integration import specs

schema = specs.fused_add_rms_norm_schema()      # 冻结：functional，不原地写 residual
schema.validate()                               # alias/mutation 不一致会抛 SchemaError
assert schema.mutation_signature() == "none"
assert schema.alias_signature() == "0:no_alias:fresh,1:no_alias:fresh"
schema.schema_hash                              # 64 hex；进入 graph/compile identity

# C3 OperatorSpec 只表达数学；mutation/alias/policy 必须显式给出，缺失即拒绝：
specs.schema_from_operator_spec(c3_spec, contract)     # 缺字段 → SchemaError
```

关键契约：可选参数必须带显式默认值；`CAST_INPUTS_TO` 必须声明 dtype；
每个输出必须显式声明 alias 关系（缺失不能被当作"新鲜输出"）。
`audit_schema_owners(paths)` 统计 Python `torch.library.define` 与 C++
`TORCH_LIBRARY/m.def` 的 owner，两个文件拥有同名算子即报冲突。

### 4.2 注册矩阵与 dispatch 真实性（`dispatch.py`）

```python
from hqsb.integration import dispatch, specs

matrix = dispatch.frozen_p0_matrix()            # 3 op × CPU/CUDA/Meta/Autocast/Autograd
snapshot = dispatch.snapshot_from_matrix("initial", matrix)
outcome = matrix.register(dispatch.RegistrationRecord(
    qualified_name=specs.OP_RMS_NORM, key=dispatch.DispatchKey.CUDA,
    implementation="other_kernel", provider="cuda_shared_lib", library="libhqsb_ops"))
assert outcome.action == "REJECTED_DUPLICATE_CONFLICT"   # 禁止 last-load-wins

capability = dispatch.OperatorCapability(op=specs.OP_RMS_NORM, provider="cuda_shared_lib",
                                         dtypes=("float16",), arch=("sm_86",))
result = dispatch.select_implementation(matrix, capability,
    dispatch.CapabilityRequest(op=specs.OP_RMS_NORM, dtype="float16", rank=2))
result.fallback_used, result.reason, result.internal_route   # requested/actual/reason

with dispatch.RedispatchGuard().enter(specs.OP_RMS_NORM, frozenset({"CUDA"})):
    ...   # 同 (op, keyset) 再进入 → RedispatchError（不靠全局计数器掩盖）
```

### 4.3 Meta/FakeTensor 元数据与图 IR（`meta.py` / `graph.py`）

```python
from hqsb.integration import meta, graph

S = meta.SymInt.symbol("S")
x = meta.TensorMeta(shape=(S, 64), dtype="float16", device="cuda", stride=(64, 1))
w = meta.TensorMeta(shape=(64,), dtype="float16", device="cuda", stride=(1,))
contract = meta.rms_norm_contract()
(out,) = contract.infer_outputs([x, w], a_last=64, b_last=64, rank=2, weight_rank=1)
assert meta.dims_repr(out.shape) == "[S, 64]"      # 符号不被具体值替换

    [{"name": "x", "op": "graph_input"}, {"name": "w", "op": "graph_input"},
```

### 4.4 pattern：结构只是候选，谓词才决定重写（`patterns.py`）

```python
spec = patterns.residual_add_rmsnorm_pattern()

                              hidden_size=64, weight_shapes={"weight": (64,)},
                              supported_versions=("1.0.0",), version="1.0.0")
decisions = patterns.scan_graph(spec, g, lambda _g, _m: ctx)
decision = decisions[0]
decision.status                      # HIT（谓词全通过）或 REJECT + 字段级 reason

outcomes = patterns.mutation_report(spec, decision.candidate, ctx,
```

## 7. 关键 bug 修复与决策记录

1. **S05 前置门被 S06 脚手架污染**（§2.3）：收紧为执行证据标记；更严而非更松。
2. **C6/C7 不改冻结 schema，改用投影 + 覆盖审计**：C1–C7 是 S01 冻结契约，
   有迁移测试依赖；S06 需要的 14 个 C6 字段与 18 类 C7 事件全部落在既有扩展点
   （`summary` / `artifact_links` / `correctness.details` / `TraceEvent.attributes`），
   并由 `c6_field_coverage()`/`c7_kind_coverage()` 证明可寻址。
   被否决方案：给 `TraceEventType` 增加枚举成员（会触碰冻结契约与迁移测试，
   且收益只是"看起来更整齐"）。
3. **`hqsb::fused_add_rms_norm` 采用 functional 契约**（E06-01 §7 要求二选一）：
   alias/functionalization/CUDA Graph 写风险最小；代价由 E06-07 测量而不是假设
   （报告中必须报告多出来的拷贝/分配）。mutable 变体若将来需要，必须是**独立私有
   op**，不得让同一 qualified name 有两种含义。
4. **目录边界**：S06 落在 `hqsb/integration`（控制平面 §3.2 的 integration 职责），
   `hqsb/compiler` 留给 S11（IR/cost model/schedule search/autotune 属 S11 范围）。
5. **CUDA Graph 默认不声称**：`configs/integration/graph_spec.yaml` 显式
   `claim_cuda_graph: false`；`claim_status()` 在未执行时返回 `NOT_RUN`，
   证据不完整返回 `NOT_CLAIMED`，两者都不会变成 PASS。
6. **修复 `detect_plateau` 的平凡平台期 bug**：原实现允许"尾部只有 1 个样本"，
   于是任何单调增长序列都会被判成 plateau（泄漏被掩盖）。改为要求尾部 ≥2 个点，
   并新增 `test_growing_series_is_detected` 负向对照。
7. **硬编码扫描器的误报与例外机制**：`HC-MODULE-PATH` 原正则把 `"layers"`
   这类普通词（cache layers）判成模块路径；`HC-MODEL-NAME` 会把
   "禁止 token 清单"本身判成泄漏。修复：正则要求真实路径续接；新增显式例外标记
   `# hqsb-hardcode-allow`，被跳过的行**计数并上报**（`allowed_lines`），
   而不是静默放宽规则。`hqsb/integration` 当前扫描结果 `ok=True`，
   且负向 fixture（植入 4 类违规）能全部检出。
8. **`AllocationAccount.reconcile` 语义修正**：参数从"内存增量"改为
   "实测节省量"，使理论节省/实测节省/g 中间量/workspace/拷贝四者可以真正对账；
   残差非零即 `explained=False`，不允许四舍五入掉。
9. **文档债务（既有，非本阶段引入）**：`docs/stage_experiments/details/*/README.md`
   指向 `S04_实验清单.md` / `S04.5_实验清单.md` 与 `../../../HQSB_项目完整剖析.md`
   的链接共 **43 处** 断裂（`scripts/check_docs.py`），根因是 `9b403aa`
   停止跟踪实验树后 S04/S04.5 清单文件在树中消失、以及控制平面文档位于
   `docs/architecture/`。协议目录冻结，本阶段**不修改**，仅登记。
10. **配置↔代码契约审计不复制 C3 全量**：YAML 只冻结 mutation/alias/policy/
   tensor 参数名等"契约字段"，其余以代码为准；两边不一致即报错，
   避免把算子参数表变成第二份会漂移的事实源。
