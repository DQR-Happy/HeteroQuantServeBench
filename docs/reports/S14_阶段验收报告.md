## 6. 代码层 vs 实验层验收结论

### 6.1 代码/接口层验收：**通过**

**通过的含义**：S14 的 12 项实验、480 个协议步骤，每一项都具备执行所需的全部能力、
函数、数据结构、驱动入口与支撑模块；一位只读过某一份 `details/S14/E14-XX_*.md` 的工程师，
拿到本代码后**不需要再补任何能力代码**即可按其"具体实验步骤"逐条执行。

| 判据 | 证据 |
|---|---|
| 480/480 步均有可导入接口 | `resolve_interfaces()`：`steps=480 ok=True failures=[]`；测试 `test_step_table_is_complete`（12 参数化） |
| 每个实验有可调用驱动入口且默认不产结论 | `scripts/experimental/run_e14.py --experiment <id>`；`verdict.json` 内 `"conclusion": false` |
| 无静默降级 | `check_no_silent_degradation` + 冻结 reason code 词汇表；测试通过 |
| 负向路径在执行前被拒 | 12 项实验各有负例矩阵；`test_experiment_has_a_negative_control`（12 参数化）全部触发 |
| 依赖边界成立 | gate R15/R16 `violations=0`；子进程导入纯度实测 0 重框架 |
| 接口层成熟度如实标注 | 全部 `SOURCE_INTEGRATED`（开发报告附录 A）；无一处标更高 |

### 6.2 实验层验收：**`BLOCKED`**
