## 1. 总体目标

建立可信的 Qwen3-1.7B FP16 Reference Runtime（`PyTorchBackend`，C4 契约），
分别刻画 Prefill 与 Decode 的算子、内存、吞吐热点，并用 Roofline/Amdahl +
真实 Profiler 数据产出 S03 的 Hotspot Decision。

## 3. 逐模块说明

### 3.1 `hqsb/benchmark/roofline.py`

**功能**：Roofline 模型（峰值 FLOPS/带宽/ridge point/可达性能/效率）、
Amdahl 定律（`amdahl_speedup`/`amdahl_max_speedup`）、热点分类
（`classify_hotspot`）、候选排序（`rank_hotspots`）、Orin FP16 预设。

**输入**：`peak_flops`、`peak_bandwidth`、kernel 名 / `time_share`。
**输出**：`RooflineModel`、`HotspotCandidate`（含 `amdahl_max`、`classification`）。

**调用**：
```python
from hqsb.benchmark.roofline import ORIN_NANO_SUPER_FP16, rank_hotspots
ranked = rank_hotspots([{"name": "aten::mm", "time_share": 0.4}])
```

**测试**：`tests/unit/core/test_roofline.py`。

### 3.2 `hqsb/benchmark/correctness.py`

**功能**：token 序列 hash（`hash_token_sequence`）、序列对比（首错位定位）、
first-token logits 容差对比、确定性验证（`verify_determinism`）、golden 对比
（`compare_against_golden`）。

**输入**：token 序列 / logits / golden 文档（含 `schema_version`）。
**输出**：`ComparisonResult`（`passed` + `details`，含 `first_mismatch_index`）。

**调用**：
```python
from hqsb.benchmark.correctness import compare_against_golden
result = compare_against_golden(golden, generated_tokens=[1,2,3])
```

**测试**：`tests/unit/core/test_correctness.py`。

### 3.3 `hqsb/benchmark/workload_config.py`

**功能**：从 `configs/benchmarks/jetson_qwen3_fp16.yaml` 加载 6 个 workload 为
`WorkloadSpec`（YAML 单一事实源），`load_workload_dicts` 供轻量读取。

**输入**：YAML 路径。
**输出**：`List[WorkloadSpec]` 或 `Dict[str, WorkloadSpec]`。
**错误**：文件缺失 / `workloads` 非列表 / 条目非法 → `ConfigError`。

**调用**：
```python
from hqsb.benchmark.workload_config import load_workload_specs
specs = load_workload_specs("configs/benchmarks/jetson_qwen3_fp16.yaml")
```

**测试**：`tests/unit/core/test_workload_config.py`。

### 3.4 `hqsb/benchmark/memory.py`

**功能**：KV cache 字节核算（`compute_kv_cache_info`/`KvCacheInfo`）、模型权重
字节（`model_weight_bytes`）、RSS/swap（`process_rss_bytes`/`process_swap_bytes`）、
CUDA 内存快照（`cuda_memory_snapshot`）、模型 KV 结构提取
（`model_kv_cache_config`）。

**调用**：
```python
from hqsb.benchmark.memory import compute_kv_cache_info
info = compute_kv_cache_info(num_layers=28, num_kv_heads=8, head_dim=128,
                             context_length=128, dtype_bytes=2)
info.total_bytes()
```

**测试**：`tests/unit/core/test_memory.py`。

### 3.5 `hqsb/benchmark/profiling.py`

**功能**：`profile_model_core` 在单个 profiler 上下文跑 prefill + decode；
`extract_operator_table` 从 profiler 结果提取结构化 operator 表
（name/count/cpu_time/cuda_time/device_memory/input_shapes），兼容 PyTorch
新旧字段名（`self_device_time_total` vs `self_cuda_time_total`）。

**调用**：
```python
from hqsb.benchmark.profiling import profile_model_core
profiler, table = profile_model_core(model, inputs, output_tokens=8)
```

**测试**：`tests/unit/core/test_profiling.py`。

### 3.6 `hqsb/backends/pytorch.py`

**功能**：`PyTorchBackend` 实现 C4 Backend 契约，包装 `load_qwen3` +
`benchmark_model_core`。幂等 `load`、`warmup`、`generate`（repetitions 次
model-core pass → `GenerationOutput`，`backend_metrics` 含 KV cache/权重/RSS/
CUDA 内存）、`health`/`metrics`/`close`。

**调用**：
```python
from hqsb.backends import PyTorchBackend
backend = PyTorchBackend(model_path="~/models/hqsb/Qwen3-1.7B",
                         verify_manifest="docs/benchmark/model_sha256_manifest.txt")
backend.load(artifact)
out = backend.generate(workload, None)
```

**测试**：`tests/unit/core/test_pytorch_backend.py`（契约合规 + 映射，无模型权重）。

### 3.7 `hqsb/hardware/jetson.py`

**功能**：Jetson 实验协议——读温度（`read_thermal_zones`/`max_temperature_c`）、
冷却等待（`cooldown`）、电源模式探测（`active_power_mode`）、平台探测
（`is_jetson`）。全部防御式（非 Jetson 返回 None/no-op）。

**测试**：`tests/unit/core/test_jetson.py`。

### 3.8 修改项

- `model_core.py`：返回新增 `raw_itl_ms`（逐 decode step 原始 ITL）、
  `kv_cache`、`model_weight_bytes`、`process_rss_bytes`、`process_swap_bytes`。
- `contracts/backend.py`：`GenerationOutput` 新增 `backend_metrics` 字段
  （per-run 内存/KV/权重核算，向后兼容默认空 dict）。
- `engine.py`：`run()` 新增 `load_artifact: bool = True`（多 workload 复用已
  加载模型时传 False，避免重复加载）。
- `loader.py`：Jetson 内存决策——`torch.cuda.mem_get_info()` 可用显存 < 6GB 时
  直接用 `device_map="auto"` + `max_memory`，避免先 OOM 再慢速磁盘 offload 重试。
