## 1. 阶段目的与核心证据（从文档推导）

### 1.1 实质性目的

`docs/stage_experiments/S11_实验清单.md` 的首句给出了 S11 的定位：

> S11 要把此前人工经验固化成：**图能被捕获，pattern 能被安全识别，IR 能 lower 到
> 目标 kernel，动态条件能 guard，autotune/cost model 出错时能回退。**

`details/S11/README.md` §1 把完整证据链与阶段核心命题写成：

> **只有当编译器能说明"捕获了什么、依据什么重写、为何这个 target 合法、为何选择这个
> kernel、制品对应哪组 guards、运行时实际执行了什么，以及失败时如何回退"，
> graph→kernel 才是一条可信的编译链。**

它同时要求证明五件事：语义正确、目标正确、决策有效、工程可靠、端到端有意义（§1）。

### 1.2 进入 S12 时必须交出的核心证据（S11 实验清单 §"阶段完成标志"）

1. E11-01 至 E11-09 通过；对外声称 AI-assisted kernel 时补齐 E11-10；
2. 至少一个真实 Qwen pattern 完成 capture→rewrite→IR→lowering→自定义 kernel→
   model correctness/performance 全链；
3. dynamic guards、graph break、recompile、cache/invalidation 和 fallback 均可诊断；
4. autotune 使用独立 holdout，cost model 报告 oracle regret；错误选择不会破坏正确性；
5. compile time、cache hit 与 steady-state model speedup 分开，IR/二进制均有版本/hash；
6. 若只有静态 FX 替换而没有 lowering/target/fallback 证据，不能宣称 AI Compiler 闭环。

**本轮的交付边界**：上述每一项都是"实验结论"，因此本阶段**只交付产出它们所需的全部能力**，
不产出结论本身（见 §8）。

### 4.1 IR、身份与 verifier（E11-01/E11-03）

```python
from hqsb.compiler import identity as ident, ir

# 1) 构造并验证一个 canonical 图（fixture 与真实 ingest 走同一构造器）
graph = ir.import_op_sequence(
    graph_id="demo",
    ops=[{"op_id": "o1", "semantic_op": "aten.add", "operands": ["x", "y"], "results": ["s"],
          "source": {"module_path": "demo.block"}, "mutation": "none", "effect_evidence": "schema"}],
    inputs=[{"value_id": "x"}, {"value_id": "y"}],
    outputs=["s"],
    constraints=(ir.ShapeConstraint("c1", "1 <= B <= 8", "variant", "user"),),
)
report = ir.verify_graph(graph)            # 14 项检查
assert report.ok, report.as_dict()
rebuilt, same_hash = ir.round_trip(graph)  # 序列化 round-trip

# 2) 三合一身份（审计键，不是框架 cache key）
gid = ident.graph_identity(normalized_graph=graph.as_dict(), op_schema_versions={"aten.add": "1.0.0"},
                           constants_hash="c", tensor_metadata={}, symbolic_constraints=("B<=8",),
                           effects=("functional",), capture_mode="dynamo_debug_backend",
                           capture_version="2.8.0")

# 3) artifact 身份 + lineage
artifact = ident.ArtifactIdentity(artifact_id="a1", ir_level=ident.IR_HQSB_TARGETED, format="json",
                                  schema_version="1.0.0", run_id="r", compile_id="c",
                                  source_commit="b83ebde", target_triple="x86_64-linux-gnu",
                                  target_arch="sm_86", canonical_hash="0" * 64)
assert artifact.validate() == []
lineage = ident.LineageGraph(); lineage.add(artifact)
```

## 6. 关键设计决策与权衡

1. **分层（§3）**：L0 身份/IR/记录 → L1 前端 → L2 重写 → L3 后端 → L4 搜索 → L5–L7 制品 →
   L8 证据；依赖只向下，且全部只依赖 `hqsb.core`。
2. **sidecar IR 而非新编译器**（ADR-S11-01）：HQSB IR 只补 PyTorch 图缺失的稳定信息。
3. **CPU 可导入性**：无模块级 torch/triton/numpy；FX/Export 惰性导入并给
   `ConfigError(reason="NOT_INSTALLED")`；由子进程探针测试固定。
4. **不产结论的默认态**：`RunDirectory.write_verdict` 需 (allow_execute ∧ 前置满足 ∧
   raw samples>0) 三者同时成立；否则一律降级 `BLOCKED` 并写原因。
5. **合法性/收益分层**（ADR-S11-03/04）：predicate 决定合法，policy/cost model 只在合法候选
   中排序；cost model 无权把非法候选变合法（注入测试固定）。
6. **fail-closed 的 everywhere**：UNKNOWN effect / 未映射语义 / 不可评估 guard / 未知 schema /
   guard false / 坏缓存 / 缺 evidence 一律拒绝并给 reason code，没有"默认安全值"。
7. **原子性与不可变性**：rewrite 返回新图；cache 事务 marker 最后；失败注入在 4 个点
   验证原图/原 entry 未变。
8. **成本口径物理分离**：compile breakdown 键集合固定且不含 steady state；
   `merge_step_timings` 把 backend 步骤映射到统一成本键。
9. **dispatch 证据双源**：至少 2 类独立证据，且 actual≠selected 必须有 reason。
10. **数据切分按语义组**：组不跨 split，final test 一次性消费，random-row 只作诊断。
11. **配置即契约**：12 份 YAML 与代码常量逐字段审计，漂移即测试失败。

被否决的替代方案与回退方式见 `S11_compiler_architecture.md` §10（ADR-S11-01…08）。

1. 重写后旧值仍指向被删除的 op，verifier 报 `UNKNOWN_PRODUCER` → 中间值丢弃 + 输出/残差值

6. `PairwiseRanker` 在全零初始化下不更新权重（margin==0 不触发）→ 改为 `margin <= 0`；
7. 机制裁决把"无证据"误判为 `REFUTED` → 引入 `refuting_observation`，无证据记 INCONCLUSIVE；

9. `DispatchRow` 无法区分"实现名"与"候选 id"，会把正常行判成静默回退 → 增加
   `actual_candidate_id`；
10. 边界测试把函数内的惰性 `torch` 导入也当作违规 → 区分模块级与函数内导入（惰性导入是
    明确要求）。
