## 0. 2026-09-21 Jetson 实验补采结论

`claim_allowed=false`，没有用单 GPU 多进程或 CPU loopback 冒充多卡结果。

## 4. 通用规则核验（`docs/stage_experiments/README.md`）

### 4.1 正确性先于性能

- ✅ `should_stop_performance()`：任一 correctness 行失败即停止该 communicator 的性能运行；
- ✅ `ledger_gate()` 在账本未闭合时 `ready=False`，且 `tp_plan_gate()` 把 `ledger_closed` 列为 E10-05 前置。

### 4.2 一次实验只改变一个主要变量

- ✅ `ScheduleIdentity` + `validate_only_variable()`：三组 schedule 只允许一个分量不同；
- ✅ `mo.holdout_check(..., policy=...)` 的 treatment 只改变 expert→rank 映射；
- ✅ `placement.alternative_placement()` 只交换两个 rank 的绑定，并把 `is_performance_claim` 结构上置 False。

### 4.3 性能结论至少 3 次独立进程运行

- ✅ `LatencySweepPlan.independent_jobs >= 3`；`ScalingPreregistration.independent_runs >= 3`；
  `ConfirmationPlan.runs_per_cell >= 3`；`AbbaConfirmation.runs_per_arm >= 3`（均结构校验）。

### 4.4 任何自动选择都记录 requested/actual/reason

- ✅ `backend.RequestedActual`（actual≠requested 且无 reason → 构造失败）；
- ✅ `overlap.PhaseShapePolicy`、`placement` 的 `fallback_reason`、`experiment.ExperimentRecord`
  的 `fallback_reason` 共同固定 handbook §5.7。

### 4.5 所有正式 run 必须生成 Evidence Manifest

- ⚠️ `EvidenceManifest`（含世界大小/拓扑 hash/plan hash/backend 版本/device_seconds/MTTD/MTTR 等 S10 扩展字段）
  已实现并有 round-trip 测试；2026-09-21 已写入每项 preflight `raw/evidence_manifest.json`，
  但仍无多 rank 科学 run manifest，不得把文件清单升级为多卡实验结论。

## 6. 代码层 vs 实验层验收结论

### 6.1 代码/接口层验收：**通过**

- ✅ E10-01~E10-10 全部 300 步均有接口，`interface_map.resolve_interfaces()` 实测 `ok=true`；
- ✅ 20 模块 + 12 冻结配置 + 驱动入口 + 240 测试 + 1 边界测试文件；
- ✅ 依赖门禁 R1–R8：0 违规 0 环；新增范围 lint 全绿；
- ✅ 负向路径有测试证明：非法 communicator 转移、错误后复用、dtype 同字节陷阱、
  非整除 shard 无 padding、重复设备/未知 UUID/rank gap/组顺序 preflight、
  缺独立 compute 的伪 overlap、无 T1 的强扩展、缺失资源格不补零、
  未解释的账本差异、过拟合 placement 的 holdout 退化、未隔离的网络故障注入；
- ✅ 所有 fallback 都带 requested/actual/reason（结构上不可省略）。

### 6.2 实验层验收：**BLOCKED**

- ❌ 目标 Jetson 只有 1×Orin，无第二加速器、无多节点/RDMA 数据路径；
- ❌ S07 P0 verdict、S08 tokenized trace、verified rank placement/data path、
  exact NCCL backend identity、冻结 model/workload pair 仍缺失；
- ✅ 已有单设备 topology preflight、240 项组件测试和 10 项逐项 raw/report；
  ❌ 但 `raw_samples=0`，没有 collective/TP/scaling/overlap/MoE-L2/fault 多 rank 科学样本；
- ⚠️ E10-07 为 `N/A_BY_ADR`（合法的"未声称"状态）。

**结论**：本任务完成了 S10 的**代码/接口层交付**；实验层因硬件与上游前置缺失而阻塞，
`BLOCKED` 是唯一合规状态，不得以"基本完成""总体通过"掩盖。
