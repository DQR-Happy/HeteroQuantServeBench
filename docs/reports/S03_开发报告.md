## 3. 逐模块说明

### 3.1 公共 API（`hqsb/rmsnorm.h`）

**功能**：RMSNorm 的稳定 C/C++ 接口，供 S04/S06/S09 复用。

**核心签名**：

```cpp
cudaError_t rmsnorm_forward(const void* input, const void* weight, void* output,
                            int64_t rows, int64_t hidden, float epsilon,
                            DType dtype, RmsNormVariant variant, cudaStream_t stream);
RmsNormVariant rmsnorm_select_variant(int64_t hidden, DType dtype);
```

**设计契约**：stream-aware、无隐藏分配、无隐藏同步、不依赖 Python/配置。

**输入**：`input`(rows×hidden 行主序)、`weight`(hidden)、`epsilon`、
`dtype`(kFloat32/kFloat16)、`variant`(kAuto/kV0/kV1/kV2)、`stream`。
**输出**：`output`(rows×hidden)，返回 `cudaError_t`。

**变体**：`kV0Shared`(FP32)、`kV1WarpShuffle`(FP32)、`kV2Vectorized`(FP32+FP16)。

### 3.2 版本实现

| 版本 | 文件 | 算法 | 假设 |
|---|---|---|---|
| V0 | `rmsnorm_v0.cu` | shared tree reduction | 正确性优先 baseline |
| V1 | `rmsnorm_v1.cu` | warp shuffle + warp-level combine | 减少 shared 流量 |
| V2 | `rmsnorm_v2.cu` | float4/half2 vectorized + warp shuffle | 128-bit 事务减少 |

各版本暴露内部 launcher（`rmsnorm_launchers.h`）供 benchmark 扫 block size，并
暴露 occupancy 查询（`rmsnorm_v*_occupancy`）供 benchmark 报告约束。

### 3.3 Dispatcher（`rmsnorm_dispatcher.cu`）

**规则**：FP16 恒走 V2（half2 处理任意列数）；FP32 hidden%4==0 走 V2，否则走 V1。
`kAuto` 委托 `select_variant`；`kReference`（CPU-only）与不支持的组合
（如 FP16+V0）返回 `cudaErrorInvalidValue`（明确 fallback 信号）。

### 3.4 Reference（`rmsnorm_reference.cu`）

FP64 累加的 CPU 实现，独立于 GPU kernel，供测试与 benchmark 复用，避免
"测试与被测代码同源"。

### 3.5 第二算子（`fused_residual_rmsnorm/`）

`out = rmsnorm(input + residual) * weight`，V0（shared）+ V1（vectorized）。
复用 `hqsb::DType`（仅头文件依赖 rmsnorm.h，不链接其 kernel）。

### 3.6 测试框架（`common/test_util.h` + `test_metrics.h`）

无 gtest 依赖的轻量断言框架（`CHECK`/`CHECK_NEAR`）与 5 项数值对比指标
（max/mean/RMSE/cosine/relative-L2）。

## 4. 调用方法

```cpp
// 应用侧（dispatcher 自动选版本）
hqsb::rmsnorm_forward(d_in, d_w, d_out, rows, hidden, 1e-5f,
                      hqsb::DType::kFloat32, hqsb::RmsNormVariant::kAuto, stream);

// 显式版本
hqsb::rmsnorm_forward(d_in, d_w, d_out, rows, hidden, 1e-5f,
                      hqsb::DType::kFloat32, hqsb::RmsNormVariant::kV2Vectorized, stream);

// 第二算子
hqsb::fused_residual_rmsnorm_forward(d_in, d_res, d_w, d_out, rows, hidden, 1e-5f,
                                     hqsb::DType::kFloat16,
                                     hqsb::FusedResidualVariant::kV1Vectorized, stream);
```

**构建与运行**：

```bash
cmake -S . -B build/jetson-release -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CUDA_ARCHITECTURES=87
cmake --build build/jetson-release --parallel
ctest --test-dir build/jetson-release --output-on-failure
./build/jetson-release/bin/hqsb_rmsnorm_bench --rows 512 --hidden 2048 --dtype fp32 --variant all
./build/jetson-release/bin/hqsb_fused_residual_rmsnorm_bench --rows 512 --hidden 2048 --dtype fp32 --variant all
```

## 5. 测试方法

| 命令 | 说明 |
|---|---|
| `ctest --test-dir build/jetson-release` | 2 个 correctness 套件（rmsnorm 33 checks、fused 15 checks） |
| `compute-sanitizer --tool memcheck ...` | host 泄漏检查（0 bytes leaked；GPU debug 受 L4T 限制） |
| `hqsb_rmsnorm_bench --variant all` | 性能矩阵（device event + host sync 双口径） |

correctness 覆盖（对照 FP64 reference，5 项指标，FP32 tol 5e-4 / FP16 tol 2e-2）：
- 常规 shape（512×1024，复现 S00 baseline）
- 非 2 次幂 hidden（100/500/1536）
- 极小/单行（hidden 1/2/3/16，rows 1/3）
- 极值（全零 / 大值 1e6–1e7 / 小值 1e-6 / 交替大值 1e10）
- FP16（1024/2048）+ FP16 奇数 hidden（3，scalar tail）
- dispatcher 选择 + 非法参数（null / 非正 shape / kReference / FP16+V0）

## 6. 性能结论（详见 benchmark report）

- RMSNorm V2（FP32 float4）：**+56%（block=256）到 +142%（block=512）** vs V0。
- 三个真实退化已定位：FP16 half2（32-bit 事务）、小 hidden（负载不均）、
  block=1024（occupancy=1）。
- Fused V1 无收益（write-then-read 依赖），与 RMSNorm 形成对照。
