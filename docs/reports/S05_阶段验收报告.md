## 1. 阶段目标回顾

`docs/stages/S05_量化与低精度推理.md`：建立 QuantLab，从量化算法、版本化
制品与数值质量贯通到低比特 Kernel 与模型推理，系统比较 RTN / GPTQ / AWQ /
SmoothQuant。验收标准三条（§49–53）：自实现 RTN + 至少两种工业方法可统一
评估；至少一个低比特路径在目标硬件有可解释的模型级收益（无收益也需证据）；
能回答量化误差/内存/带宽/计算/Runtime 支持的完整因果链。
