## 1. 总体目标

建立后续所有模型、算子、量化、Backend、Serving、Benchmark 共同依赖的稳定
Contract（C1–C7）、注册机制、统一配置/错误/日志体系、版本化 schema 与迁移、
Python 打包、测试金字塔与 CI，使各模块可独立开发而不产生循环依赖。

核心交付物：`hqsb/core` 稳定地基 + `DummyBackend` reference example +
backend-interface benchmark engine + legacy 迁移工具 + 完整测试 + 文档模板。

## 3. 逐模块说明

### 3.1 `hqsb/core/errors.py`

**功能**：统一错误分类与进程退出码。

**类层次**：`HqsbError`（基类，exit_code=1）→
`UsageError`(2)、`ConfigError`(3)、`SchemaError`(4)、`RegistryError`(5)、
`BackendError`(6)、`CapabilityError`(7)、`ArtifactError`(8)、`BenchmarkError`(9)。

**输入**：`message: str`、可选 `details: dict`（结构化上下文）。

**输出**：异常实例，带 `exit_code` 属性。

**调用方法**：

```python
from hqsb.core import ConfigError, exit_code_for
raise ConfigError("bad config", details={"field": "x"})
code = exit_code_for(exc)  # -> 3
```

**测试**：`tests/unit/core/test_errors.py`。

### 3.2 `hqsb/core/ids.py`

**功能**：生成 run/trace/span 标识符。

**API**：`new_run_id() -> "run_<ms>_<hex8>"`；`new_trace_id() -> 32 hex`；
`new_span_id() -> 16 hex`。

**测试**：`tests/unit/core/test_ids.py`。

### 3.3 `hqsb/core/logging.py`

**功能**：JSON lines 结构化日志 + `contextvars` 传递 trace/span 上下文。

**API**：`configure_logging(level, json_format=True)`；`set_trace_context(trace_id,
span_id=None)`；`get_trace_id()`；`get_span_id()`；`JsonLineFormatter`。

**输出**：每行 JSON 含 `ts/level/logger/message`，上下文存在时含
`trace_id/span_id`，`extra` 结构化指标被合并。

**测试**：`tests/unit/core/test_logging.py`。

### 3.4 `hqsb/core/contracts/*`（C1–C7）

所有 contract 继承 `VersionedModel`（`extra="forbid"` 拒绝未知字段，自动
stamp `schema_version`）。均为 Pydantic v2 模型，支持
`model_validate(dict)` / `model_dump(mode="json")` / `model_dump_json()`。

| Contract | 关键字段 | 输入校验 |
|---|---|---|
| `ModelArtifact` | model_id/source/file_hashes/architecture/dtype/quantization | 必填 model_id/source/architecture/dtype |
| `WorkloadSpec` | name/batch/input_tokens/output_tokens/seed/sampling/warmup/repetitions/concurrency/timeout | token ≥ 1, batch ≥ 1, repetitions ≥ 1 |
| `OperatorSpec` | name/semantic_version/inputs/outputs/device/tolerance/implementation | workspace ≥ 0 |
| `BackendCapability` | name/supported_dtypes/max_batch/streaming/quant/distributed | — |
| `Backend` (ABC) | load/warmup/generate/health/metrics/close/stream | 抽象方法 |
| `QuantArtifact` | algorithm/bits/granularity/symmetric/group_size/accuracy | 1 ≤ bits ≤ 8 |
| `BenchmarkResult` | run_id/timestamp/environment/workload/raw_samples/summary/correctness/resource | 必填 run_id/timestamp/environment |
| `TraceEvent` | event_type/timestamp_ns/trace_id/span_id/attributes | timestamp ≥ 0 |

**调用示例**：

```python
from hqsb.core import ModelArtifact, WorkloadSpec
m = ModelArtifact(model_id="Qwen/Qwen3-1.7B", source="modelscope",
                  architecture="Qwen3ForCausalLM", dtype="float16")
w = WorkloadSpec(name="short", input_tokens=128, output_tokens=32)
```

**测试**：`tests/unit/core/test_contracts.py`。

### 3.5 `hqsb/core/schema/versioning.py` + `migrate.py`

**功能**：
- `SchemaVersion`：严格三段式语义版本 + 全序比较。
- `migrate_document(document, current, migrations)`：显式迁移执行器，
  拒绝缺失/畸形/未来版本，按升序组合迁移步骤。
- `migrate_legacy_golden` / `migrate_legacy_result` / `migrate_any`：
  S00 legacy 文档 → `BenchmarkResult`。

**输入**：raw dict（含 `schema_version`）。
**输出**：迁移后的 dict 或 `BenchmarkResult` 实例。

**测试**：`tests/unit/core/test_schema_versioning.py`、`test_migration.py`。

### 3.6 `hqsb/core/config/loader.py`

**功能**：分层配置加载（defaults < file < env < CLI），Pydantic 校验
（未知字段拒绝 + 类型检查），确定性 SHA256 config hash。

**API**：

```python
from hqsb.core import ConfigLoader
loader = ConfigLoader(MyConfigModel)            # 默认 HQSB_ 前缀、__ 分隔
config = loader.load(defaults=..., path=..., environ=..., cli=...)
config, h = loader.load_with_hash(...)
```

环境变量规则：`HQSB_BATCH_SIZE=16` → `batch_size=16`（前缀剥离 + 小写 + JSON
标量强制转换）。

**测试**：`tests/unit/core/test_config.py`。

### 3.7 `hqsb/core/registry/registry.py`

**功能**：通用 `Registry[T]`（注册/查找/卸载/迭代 + 冲突检测）与
`RegistryHub`（backends/operators/quantizers/monitors/reporters 五个标准注册表）。

**API**：

```python
hub = RegistryHub()
hub.backends.register("dummy", make_dummy_backend)
backend = hub.backends.get("dummy")()
```

**错误**：重复注册（不同对象）→ `DuplicateRegistrationError`；
缺失查找/卸载 → `RegistryLookupError`。

**测试**：`tests/unit/core/test_registry.py`。

### 3.8 `hqsb/backends/dummy.py`

**功能**：`DummyBackend` 参考实现，确定性生成 token（seed 驱动），
无模型权重/GPU 依赖。`make_dummy_backend()` 工厂。

**测试**：`tests/unit/core/test_dummy_backend.py`。

### 3.9 `hqsb/benchmark/engine.py`

**功能**：`BenchmarkEngine` 对任意 `Backend` 编排一次 benchmark，产出
`BenchmarkResult`。含能力校验（batch/dtype）、determinism 正确性门禁、
summary 统计（复用 `metrics.latency_summary`）、artifact/config hash 绑定。

**API**：

```python
from hqsb.benchmark.engine import BenchmarkEngine, run_backend
result = BenchmarkEngine(backend).run(workload, artifact=artifact)
result = run_backend(backend, workload)
```

**测试**：`tests/unit/core/test_dummy_backend.py::TestBenchmarkEngine`。

### 3.10 `scripts/migrate_legacy.py`

**功能**：CLI 将 legacy golden/result 迁移为新 schema。
**用法**：`python scripts/migrate_legacy.py <input.json> <output.json>`。
**退出码**：0 成功 / 1 文件错误 / 2 用法错误 / 4 schema 错误。

### 3.11 `scripts/check_docs.py`

**功能**：检查 `docs/` 与 `README.md` 中相对链接是否断裂。
**用法**：`python scripts/check_docs.py`。
